# 📸 Dont Follow Me?

Una extensión de navegador que realiza web scraping en Instagram para mostrar:
- Seguidores
- Seguidos
- Personas que sigues pero que **no te siguen de vuelta**

## 🚀 Características

- Web scraping directo desde el DOM de Instagram.
- Comparación visual de seguidores vs. seguidos.
- No requiere autenticación externa.
- Totalmente local.
- Ligera y rápida.

## 🧠 Tecnologías

- JavaScript
- HTML
- CSS
- Chrome Extensions API (Manifest v3)

## 🛠️ Instalación

1. Clona el repositorio:
   ```bash
   git clone https://github.com/CarlosPad08/dont-follow-me.git
   ```
2. Abre tu navegador en modo desarrollador.

3. Carga la extensión manualmente:

    - Ve a chrome://extensions/

    - Activa “Modo desarrollador”

    - Clic en “Cargar extensión descomprimida”

    - Selecciona la carpeta del proyecto
